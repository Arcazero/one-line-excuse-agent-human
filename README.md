One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline. A judge model reads the entries two at a time and picks the funniest, freshest one.

> I outsourced the deadline to a future version of myself, and he's ignoring my messages too.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the excuse to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
